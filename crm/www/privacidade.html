Política de Privacidade

CRM Stratcompany · Última atualização: 19 de setembro de 2026

A Stratcompany ("nós") oferece um CRM para escritórios de advocacia e agências. Esta página explica quais dados o CRM usa e como funciona a conexão opcional com o Google Drive.

1. Quem é o responsável

Stratcompany. Contato para assuntos de privacidade: stratcompan@gmail.com. Site: stratcompany.com.

2. Quais dados o CRM guarda

Os dados que o próprio escritório cadastra: leads, contatos, negociações, propostas, tarefas, dados financeiros e arquivos. Cada escritório tem o seu próprio ambiente, isolado dos demais. A Stratcompany não usa esses dados para outra finalidade além de prestar o serviço.

3. Conexão com o Google Drive (opcional)

A conexão só acontece se o usuário clicar em "Conectar Google Drive" e autorizar.

  • Permissão solicitada: somente drive.file. Com ela, o CRM acessa apenas os arquivos e pastas que ele mesmo criou no Drive do usuário. O CRM não lê, não lista e não altera nenhum outro arquivo do Drive.
  • Para que usamos: salvar no Drive do usuário os documentos gerados no CRM, como propostas comerciais, orçamentos, contratos e relatórios.
  • Onde ficam as credenciais: a autorização fica guardada, de forma protegida, apenas no ambiente do próprio escritório.
  • Compartilhamento: não vendemos, não transferimos e não compartilhamos dados obtidos do Google com terceiros. Não usamos esses dados para publicidade nem para treinar modelos de inteligência artificial.
  • Como desconectar: no CRM, em Configurações → Integrações → Google Drive → Desconectar. Também é possível revogar o acesso em myaccount.google.com/permissions. Os arquivos já salvos permanecem no Drive do usuário.

O uso e a transferência das informações recebidas das APIs do Google seguem a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

4. Base legal e direitos (LGPD)

Tratamos dados para executar o contrato de uso do CRM e, no caso do Google Drive, com o consentimento do usuário. O titular pode solicitar acesso, correção, exclusão ou portabilidade dos seus dados pelo e-mail acima.

5. Segurança e retenção

Usamos conexão criptografada (HTTPS), controle de acesso por usuário e cópias de segurança. Os dados são mantidos enquanto o contrato estiver ativo e apagados a pedido do escritório após o encerramento.

6. Alterações

Podemos atualizar esta política. A data no topo mostra a última revisão.
